# Standing Rules (Citation Copy)

These fourteen `.mdc` files are the ambient layer used with the prompt library
in `docs/coding-prompts-1.md`. Every file is `alwaysApply`: in context for every
generation, never invoked.

The library and this rule set accreted concurrently across the project rather
than being designed up front. Every rule traces to an observed defect in
generated code. The files are reproduced as used, including imperfections and
any duplication with the library's "Standard coding rules" block.

Each `.mdc` body is byte-identical to the live source. Don't treat this
directory as a Cursor rules folder; it is a citation copy. The live files stay
under the private game repository and aren't edited by editorial work.

The series cites this set from Post 4 (the method) and Post 6 (which rules
held, and why the set is short).
